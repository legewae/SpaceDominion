# SpaceDominion

Учебный проект по дисциплине ООАиП: многопользовательская космическая стратегия.

Игроки регистрируются, собираются в матчи через матчмейкинг, воюют за территории,
получают доход от источников и изменение рейтинга ELO по итогам матча.

Проект намеренно сделан как «код без игры»: нет UI и консольного клиента, всё
поведение проверяется тестами, а оценивается архитектура, соблюдение SOLID и
документация решений.

## Стек

- .NET 9 (C#), xUnit, Moq, coverlet;
- IoC-контейнер преподавателя: `Common/core.dll` (`App.Ioc`) и `Common/scopes.dll` (`App.Scopes`);
- CI: GitHub Actions — форматирование, сборка, тесты, покрытие не ниже 90%.

## Структура

```
SpaceDominion.sln
├── Common/                 core.dll, scopes.dll — IoC-контейнер
├── SpaceDominion.Lib/      домен, команды, инфраструктура
├── SpaceDominion.Tests/    xUnit + Moq
└── docs/                   вики проекта: архитектура, решения (ADR), правила
```

## Сборка и тесты

```bash
dotnet build
dotnet test
```

Проверка форматирования (как в CI):

```bash
dotnet format --verify-no-changes
```
