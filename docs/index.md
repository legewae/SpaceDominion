# Документация SpaceDominion

Вики проекта живёт в репозитории — так решения версионируются вместе с кодом.

| Документ | О чём |
|---|---|
| [plan.md](plan.md) | План работ: блоки, PR, критерии готовности |
| [glossary.md](glossary.md) | Единый язык проекта (термины) |
| [architecture.md](architecture.md) | Слои, поток команды, скоупы |
| [ioc.md](ioc.md) | Контейнер зависимостей и правила работы с ним |
| [code-style.md](code-style.md) | Соглашения: комментарии, имена, форматирование |
| [testing.md](testing.md) | Стратегия тестирования и arch-тесты |
| [adr/](adr/) | Принятые архитектурные решения |

## Правила

1. Каждое архитектурное решение оформляется ADR по шаблону [adr/0000-template.md](adr/0000-template.md).
2. Обновление документации входит в definition of done каждого PR.
3. Если код и документ противоречат друг другу — это дефект, а не «так и задумано».
