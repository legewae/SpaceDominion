# Тестирование

## Пирамида

| Уровень | Что проверяет | Пример |
|---|---|---|
| Юнит | поведение одного класса/команды | `SendCommandTests` |
| Сценарный | команда → события → состояние/проекция | «покупка корабля списывает деньги и спавнит корабль» |
| Интеграционный | два матча/два сервера, изоляция скоупов | PR-20, PR-21 |
| Архитектурный | правила проекта, а не поведения | «`new` только в стратегиях» |

## Правила

1. Тест проверяет поведение, а не «вернулся не null».
2. Название: `Method_WhenCondition_ExpectedBehavior`.
3. Время — только через `IClock`/`VirtualClock`; `Thread.Sleep` и `DateTime.Now` запрещены.
4. Каждый PR добавляет тесты вместе с кодом; покрытие не ниже 90% (сгенерированный код исключается через `[ExcludeFromCodeCoverage]`).

## Arch-тесты (появятся в PR-10)

- `new` встречается только в стратегиях/регистрациях/фабриках.
- `App.Ioc` — только в composition root, регистрациях и сгенерированных типах.
- Все реализации доменных интерфейсов созданы генератором адаптеров.
- В доменных сборках нет `DateTime.Now`, `Thread.Sleep`, мутабельных `static`.

## Локальный запуск

```bash
dotnet test
dotnet test --collect:"XPlat Code Coverage"   # покрытие в TestResults/
```
