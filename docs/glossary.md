# Глоссарий (единый язык проекта)

| Термин | Значение |
|---|---|
| **Аккаунт** | Учётная запись игрока с логином и паролем (PBKDF2-хеш). Содержит ровно один профиль. |
| **Профиль** | Игровая сущность: уникальный юзернейм, отображаемое имя, рейтинг ELO. |
| **Юзернейм** | Уникальное имя профиля; при смене старый освобождается. |
| **Слот профиля** | Разрешённое количество профилей на аккаунт (в проекте — 1). |
| **Матчмейкинг** | Очередь поиска противников с окном рейтинга ±100 и таймаутом 60 с. |
| **Матч** | Игра от 2 до 8 игроков; проходит состояния: создан → согласие → готовность → сервер → запущен → завершён/отменён. |
| **Согласие** | Подтверждение участия в матче; на все согласия даётся 20 с. |
| **Территория** | Клетка поля, принадлежащая игроку; может содержать источник дохода. |
| **Источник дохода** | Объект на территории, приносящий владельцу деньги каждые 30 с. |
| **Корабль** | Боевая единица игрока: HP, патроны, перезарядка, позиция. |
| **Захват** | Переход территории к игроку, чьи корабли находятся в её клетке, при отсутствии чужих кораблей. |
| **Выбывание** | Игрок потерял последнюю территорию и больше не участвует в матче. |
| **Исход матча** | Победитель (больше территорий), ничья или прерывание. |
| **ELO** | Рейтинг; изменение считается по местам в матче (K = 32), ничья и прерывание не меняют рейтинг. |
| **Read model** | Проекция для чтения: лидерборд, история матчей, территории, позиции объектов. |
| **Политика** | Обработчик события, который создаёт следующую команду. |
| **Команда** | Объект, инкапсулирующий изменение состояния (`ICommand`). |
| **Событие** | Факт, произошедший в домене; публикуется после успешного выполнения команды. |
| **Скоуп** | Набор зависимостей, разрешаемых в рамках одного матча. |
| **Сервер (эмуляция)** | Узел, владеющий набором матчей; в проекте эмулируется в одном процессе. |
